# 🍁 Maple Assistant

עוזר Claude שיושב מעל MapleStory Classic World. לוחצים על מקש קיצור, שואלים שאלה, מקבלים תשובה - בלי לצאת מהמשחק.

## התקנה
1. היכנס ל-**Releases** (בצד ימין של הדף) והורד את `MapleAssistant.exe`.
2. הפעל אותו. אם מופיע "Windows protected your PC": **More info ← Run anyway** (פעם אחת בלבד).
3. בהפעלה הראשונה הדבק מפתח API מ-[console.anthropic.com](https://console.anthropic.com) ← API Keys.

## שימוש
| פעולה | איך |
|---|---|
| פתיחה | אייקון **Maple Assistant** בשולחן העבודה, או `Ctrl+Shift+A` (ניתן לשינוי בהגדרות) |
| שליחת שאלה | Enter |
| הסתרה (ממשיך ברקע) | Esc או — |
| סגירה מלאה | ✕ |
| ⚡ מהיר / 🔍 מעמיק | מהיר = זול מאוד. מעמיק = חכם יותר + חיפוש באינטרנט |
| 📷 | צירוף צילום מסך של המשחק לשאלה |
| 🆕 | שיחה חדשה |

- **המשחק חייב לרוץ ב-Windowed או Borderless**, לא Fullscreen, כדי שהחלון יופיע מעליו.
- העלות מוצגת מתחת לכל תשובה, יחד עם סך ההוצאה החודשית (הערכה). תקרה אמיתית מגדירים ב-Console ← Limits.
- העוזר נותן עצות בלבד ולא נוגע במשחק עצמו.

## פרטיות
מפתח ה-API נשמר רק במחשב שלך (Windows Credential Manager). צילומי מסך נשלחים ל-Anthropic רק כשאתה שולח שאלה עם 📷 מסומן.

## לחברים שרוצים להשתמש
1. הורידו את `MapleAssistant.exe` מ-[Releases](https://github.com/michaelarnsb-stack/maple-assistant/releases/latest).
2. כל אחד צריך **מפתח API משלו** מ-[console.anthropic.com](https://console.anthropic.com), עם קרדיט (כמה דולרים לחודש). אל תשתפו מפתחות.
3. השימוש על אחריותכם: זו תוכנה לא רשמית ולא חתומה, ולא נבדקה מול מערכת ה-anti-cheat של Nexon.
